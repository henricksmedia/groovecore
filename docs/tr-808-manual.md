Screen Structure
Main window
- [GAIN] knob: Adjusts the gain of each instrument.
- [PAN] knob: Adjusts the pan (left/right position) of each instrument.
- [TUNING] knob: Adjusts the pitch of each instrument.
- [PANEL] button: Switches the instrument edit section’s display to GAIN, PAN, and TUNE (Bass Drum only).
- Instrument pads: Sound is produced when clicked; light up during playback to indicate steps.
- [A]–[H] buttons: Switch the variation (A–H) that plays; multiple selection with Shift key.
- [START/STOP] button: Plays or stops the pattern.
- [EDIT] button: Displays the edit window.
- [LIST] button: Displays the Memory Select window.
- Display (upper line): Shows the bank name.
- Level meter: Shows the output level.
- Display (center line / lower line): Shows the selected pattern name and kit name.
- [ ] [ ] buttons: Recall the previous or next pattern or kit.
- [WRITE] button: Saves the pattern or kit.
Instrument edit section
- [LEVEL] knob: Adjusts the volume of the instrument.
- [TONE] knob: Adjusts the tension of the head for bass or snare drum; adjusts tonal character for cymbal.
- [TUNING] knob: Adjusts the pitch of the tom or conga.
- [DECAY] knob: Adjusts the decay of the sound.
- [SNAPPY] knob: Corresponds to the resonating wires of a snare drum.
- Instrument select switch: Selects one of two instruments.
- [VOLUME] knob: Adjusts the volume.
- [INSTRUMENT SELECT] knob: Selects the instrument indicated by the instrument pads.
- [SHUFFLE] knob: Adjusts the amount of shuffle (swing).
- [OPTION] button: Makes various settings or authorizes the software.
- [HELP] button: Displays help.
- [ABOUT] button: Displays information about TR-808 Software Rhythm Composer.
Zoom: Drag the bottom-right corner of the window to resize.

Sound Engine Structure
- What Is a “PATTERN”?: The performance data recorded is called a “pattern.” Each pattern can have eight variations (A–H).
- What Is a “KIT”?: The 11 instruments are collectively called a “kit.” The pattern plays the instruments of the currently selected kit.
- What Is a “Bank”?: A “bank” is a set of 128 patterns and kits. By switching banks, you can recall a large number of patterns and kits. You can save a bank as a file.

Page 5
Edit Window
- EDIT VARIATION SELECT buttons: Select the variation (A–H) or current playing variation to edit.
- [SCALE] button: Selects the scale; changes each time pressed.
- [LAST STEP] button: Specifies the length of the pattern.
- [WEAK] button: Turn on to enter weak beats.
- [FLAM] button: Turn on to enter a flam; FLAM TYPE sets the interval (0–48 msec).
- [SUB STEP] button: Turn on to enter sub steps; SUB STEP TYPE sets the type (Duplets, Triplets, Quadruplets).
- TOTAL ACCENT–BASS DRUM: Sets whether the instrument plays or not; accented steps match TOTAL ACCENT during playback.
- [M] (mute) / [S] (solo) button: Specify mute/solo settings.
- [SHUFFLE] slider: Specifies the amount of shuffle for each instrument.
- Step buttons: Set how sounds play for each step; light up white during playback.

Page 6
Edit Window (cont.)
- Inputting Weak Beats: Click [WEAK] button, turn on steps for weak beats (lit dimly); use Shift key as shortcut.
- Specifying a Flam: Click [FLAM] button, select FLAM TYPE, turn on steps for flam; combinable with weak beats.
- Inputting Sub Steps: Click [SUB STEP] button, select SUB STEP TYPE, turn on steps for sub steps; combinable with weak beats.

Page 7
Edit Window (cont.)
- Editing a Variation: Right-click EDIT VARIATION SELECT for Copy, Paste, Clear, or Swap functions.
- Editing an Instrument: Right-click instrument name for Copy, Paste, Clear, Invert, or All functions.
- Placing a Pattern in a DAW Track: Use [OPTION] button to choose MIDI or audio data; drag and drop supported.

Page 8
Edit Window (cont.)
- DAW Multi-Out Support: Different outputs for each instrument (Main out, Sub out 1–11).
- How Note Numbers Select Sounds or Variations: Note numbers 24–75 select variations or instruments.
- About CC (Control Change): CC# 7–88 control various parameters (VOLUME, SHUFFLE, TUNING, etc.).

Page 9
Patterns/Kits and Banks
- [LIST] button: Opens Memory Select window.
- [WRITE] button: Saves the edited pattern/kit.
- [RENAME] button: Renames the selected memory.
- [NEW] button: Creates a new empty bank.
- [DELETE] button: Deletes the selected bank.
- [LOAD] button: Loads a bank from a file.
- [SAVE] button: Exports a bank as a file.
- [READ] button: Loads a memory from a bank.
- Changing to Other Bank: Click Bank field, select from list.
- Exporting/Importing a Bank: Use [SAVE] or [LOAD] button.

Page 10
Patterns/Kits and Banks (cont.)
- Creating/Deleting a Bank: Use [NEW] or [DELETE] button.
- Renaming a Bank: Select bank, click [J] button, edit name.
- Loading/Saving a Pattern or Kit: Use [READ] or [WRITE] button.
- Renaming a Pattern or Kit: Use [RENAME] button.

Patterns/Kits and Banks (cont.)
- MIDI Learn Function: Right-click parameter, choose “Learn MIDI CC,” operate MIDI device; cancel with “Forget MIDI CC.”
